# SKILL-356 - runtime-infra-sqlite-boundaries-and-simplicity

## Mode

decomposed

## Intended outcome

Reduce `runtime-infra-sqlite` to the adapter its ports need: one transaction implementation with symmetric typed failures; a session factory that takes the resolved environment, clock, and diagnostics port instead of re-resolving or reaching for them; every degradation recorded through `RuntimeDiagnostics` or a closed state instead of `java.util.logging` or silence; one binder instead of 27 index constants; wire tokens owned once by an enum or a `*PayloadKeys` object and scanned by the guard; an `internal` module whose only public types are the four the composition root constructs, with a `testFixtures` source set carrying the database fixture other modules' tests use; the goal-runner manifest and outcome stores implementing their ports directly instead of through same-module interfaces, forwarding implementations, a dependency bag, and bridge builders; schema evolution reduced to the base DDL plus the name-keyed ledger with `PRAGMA user_version` stamped by the ledger and legacy repairs run once as recorded migrations instead of on every establishment or on every read; and the unused Gradle dependencies, dead ambient defaults, test-only production entry points, and misplaced tests deleted, while keeping the module graph, the ports, every SQL statement's effect on well-formed data, the WAL and busy-timeout connection setup, the readiness gate design, the migration ledger and its compatibility tests, and every passing test's observable assertion unchanged.

## Constraints

- Follow runtime-kotlin/ARCHITECTURE.md design principles, docs/code-principles.md, docs/observability-policy.md, and AGENTS.md. Keep the eleven Gradle modules, the composition root, the `implementation` edges pinned in `RuntimeModuleCatalog`, and the infra → ports, domain, contracts direction.
- Respect recorded decisions: WAL plus `busy_timeout` on every connection (2026-06-26), one identity read per `ensureReady` (SKILL-239 subtask 2), shrink-only infra ambient baselines (2026-09-03), guard ceilings move by decision not by baseline (2026-09-04), `JvmSystemClock` lives in `runtime-contracts` and is bound to `Clock` at the composition root (2026-09-03), the six diverged near-duplicates with `runtime-application` stay distinct (2026-09-03), and the fat `UnitOfWork` is the persistence boundary (2026-09-06).
- No ORM, query builder, migration library, connection pool, long-lived connection, coroutine layer, new module, or new port family. The only port change is the additive `UnitOfWork.featureTaskPhaseSettlements` property and the deletion of port methods no consumer calls where this module is the sole implementer.
- Preserve every SQL statement's effect on well-formed data, the base DDL, migration names already in the ledger, delivery and lease semantics, payload bytes on the telemetry wire, and every passing test's observable assertion. Only malformed durable rows and configuration defects change their failure identity.
- Kotlin under `runtime-kotlin` carries no `//` comments and no non-KDoc block comments; files stay under 1,200 lines and 40 functions without count splits; no new suppression, baseline row, or exemption.
- Deletion follows a fresh reference census plus compilation and the full runtime-kotlin test suite; the recorded census is evidence, not authority.
- Re-read the owning documents and current source hashes before each subtask. Subtasks 2 and 3 rebase on subtask 1 and re-census before editing.

## Non-goals

- Changing `DatabaseSessionFactory`, `GoalRunnerManifestStore`, or `GoalRunnerWorkflowOutcomeStore` signatures, or the repository port method sets consumers call.
- Moving the module under `runtime-infra/`; SKILL-354 owns that.
- Deleting `MigrationLedger.ensureNameKeyed`, the legacy fixture tests, or any compatibility path without a decision entry naming a support window.
- Rewriting SQL for performance, adding indexes, or changing table shapes beyond the `user_version` stamp.
- Touching the `runtime-application` near-duplicates of goal-runner helpers.
- Renaming the `SQLite*`, `Sqlite*`, or `Database*` prefixes.
- Certification against private Reddit, Microsoft, or Meta standards.

Resolve F-001, F-003, F-005, F-006, F-008, and F-009 in [investigation.md](investigation.md).

Own every file under `runtime-infra/fs` (`src/main`, `src/test`, `src/repoTest`, `build.gradle.kts`, `agent/history.md`), the new module directories `runtime-infra/host`, `contracts`, `skills`, `launcher`, and `workflow`, `settings.gradle.kts`, the project dependencies of `runtime-core`, `runtime-application`, `runtime-engine`, `runtime-cli`, and `runtime-mcp`, every import of `skillbill.infrastructure.fs.*` in those modules, the resource-path constants in `runtime-contracts` and `GateJvmResolver`, `RuntimeModuleCatalog`, `PrincipleEnforcementInventory`, the sixteen `runtime-core` architecture tests that name fs paths, the infrastructure baseline files, a new import-direction test for the skills package order, and the module and package sections of `runtime-kotlin/ARCHITECTURE.md`, `docs/code-principles.md`, `docs/internal-skills-architecture.md`, `docs/skill-source-generation.md`, `docs/agent/history.md`, and `runtime-kotlin/agent/decisions.md`.

Re-run the edge census on the branch head, then create the five modules and move every production file by the investigation's placement rules: `jvm`, `concurrency`, the `Jdk*` ports, `CanonicalRepositoryRoot`, `FileSystemRepoLocalConfig`, `FileTelemetryConfigStore`, `TelemetryConfigPaths`, and the primitive owners SKILL-353 created go to host; `contracts/**`, `phaseoutput/**`, the validator port implementations, `FeatureTaskRuntimeArtifactMapBridge`, and `WorkflowStateSnapshotWireMapper` go to contracts; `agentaddon`, `nativeagent`, `scaffold`, `install`, `skillremove`, the root scaffold, native-agent, install, overlay, baseline, uninstall, and catalog adapters, `FileSystemRepoValidationGateway`, `McpRegistrationOperations`, `McpJsonConfig`, and `McpTomlConfig` go to skills; `launcher/**` less those three, `GovernedReviewMcpConfigWriter`, `InstallerProcessAdapter`, `AgentRunReviewIsolationResolver`, and `FileSystemReviewLaunchAgentStaging` go to launcher; the `Git*` files, `GhGoalPullRequestPort`, `FileSystemCheckedOutBranchSource`, `FileSystemDiffResolver`, the review adapters, the feature-task and decomposition stores, `goalplanning`, and `validation` go to workflow under `git`, `review`, `featuretask`, `goalplanning`, and `validation`. Rename packages to `skillbill.infrastructure.<module>` keeping area sub-packages, rewrite every import inside and outside the modules, and rename the classpath resource prefixes with their reader constants and the golden manifest. Write each module's build script with only the project and library dependencies its files import; declare the governed copies for host, contracts, and workflow through the convention plugin; delete `runtime-infra/fs`, the area source sets, and `verifyInfraFsAreaCompile`. Move each test, `repoTest` file, and resource to the module whose code it drives, place the four dependency-free helpers as host test fixtures and `ConformingPlatformPackFixture` as a skills test fixture, and declare the test-fixture edges. Compile, and where a cross-module reference fails on `internal`, make that declaration public; then run the per-module reference census and make every name with no consumer outside its module `internal` or delete it. Add the skills import-direction test, update the catalog, edge expectations, scan cases, and package roots, re-record baselines per module, relocate `agent/history.md` to `runtime-infra/agent/history.md`, rewrite the documents, and record the superseding decision.

## Acceptance Criteria

1. `settings.gradle.kts` includes `runtime-infra:host`, `runtime-infra:contracts`, `runtime-infra:skills`, `runtime-infra:launcher`, `runtime-infra:workflow`, `runtime-infra:http`, and `runtime-infra:sqlite`; `runtime-infra/fs` does not exist; every production file that existed under `runtime-infra/fs/src/main` exists in exactly one new module, and `git log --follow` shows its history.
2. Each new module's production files are under `skillbill.infrastructure.<module>`; each module's `build.gradle.kts` declares only `runtime-ports`, `runtime-domain`, `runtime-contracts`, and the sibling edges skills to contracts and host, launcher to skills and host, workflow to skills, contracts, and host; no other `project(...)` edge exists in any infrastructure main configuration; `RuntimeModuleCatalog.moduleEdgeExpectations` matches and `RuntimeCoreCompositionOnlyTest` pins `runtime-core` to seven infrastructure `implementation` edges.
3. No `infraFs*Area` source set, area compile task, or `verifyInfraFsAreaCompile` exists; an import-direction test in `runtime-core` asserts the skills package order (agentaddon, nativeagent, scaffold, install, skillremove, module root) with an empty violation list, and `ARCHITECTURE.md` records that order.
4. No `skillbill.infrastructure.fs` or `skillbill/infrastructure/fs` string exists in `runtime-kotlin` source, resources, build scripts, or tests, in `docs/`, or in `AGENTS.md`; the 31 `runtime-contracts` literals and `GateJvmResolver.GUARD_CLASSPATH_RESOURCE` name `skillbill/infrastructure/contracts/` and `skillbill/infrastructure/host/jvm/`; `GovernedResourceCopyParityTest` passes with a golden manifest whose content hashes are unchanged from subtask 1.
5. Every `test` and `repoTest` file that existed under `runtime-infra/fs` exists in exactly one new module; host and skills carry `java-test-fixtures`; the summed test count across the five modules is at least 1,518 for `test` and 180 for `repoTest`; `RuntimeModuleCatalog.testFixturesProjectDependenciesByModule` lists the new edges and `RuntimeAdapterDependencyAllowlistTest` passes; no infrastructure build script contains `friendPaths`.
6. After the per-module census, every public top-level name in the five modules has a consumer outside its module in main, test, or fixture sources, or is `internal`, or is deleted; `RuntimeCompositionGuardArchitectureTest` and the inject-defaults census pass.
7. Each of the five modules has four baseline files; package-cycle baselines are empty; the summed ambient-environment rows are at most 104; no baseline row is added that the `runtime-infra-fs` baseline did not contain.
8. `runtime-kotlin/ARCHITECTURE.md` lists the seven infrastructure modules in its module list, graph, Gradle Modules, and Package Ownership sections and names no `runtime-infra-fs`; the four `docs/` files and `docs/agent/history.md` name the new modules and paths; `runtime-infra/agent/history.md` exists with the former fs history; `runtime-kotlin/agent/decisions.md` has an entry that supersedes the 2026-06-12 single-adapter-module decision, citing the measured edges and dependency profiles; `RuntimeArchitectureDocumentationTest` passes.
9. All modules compile; `./gradlew check` on runtime-kotlin passes including `repoTest` and `:convention:check`; `:runtime-cli:installDist` and `:runtime-mcp:installDist` succeed and `skill-bill --version` runs from the installed distribution.

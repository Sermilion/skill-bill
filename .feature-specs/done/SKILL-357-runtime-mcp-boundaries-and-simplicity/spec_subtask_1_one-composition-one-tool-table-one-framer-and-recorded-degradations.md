# SKILL-357 Subtask 1 - One composition, one tool table, one framer, and recorded degradations

Issue key: SKILL-357

## Scope

Resolve F-001, F-003, F-004, F-005, F-006, F-007, F-008, F-009, and the module-owned part of F-010 in [investigation.md](investigation.md).

Own every file under `../../../runtime-kotlin/runtime-mcp/src/main/kotlin/skillbill/mcp` except the input-schema declarations subtask 2 replaces (`McpInputSchemas.kt`, `McpInputSchemaPrimitives.kt`, and the `inputSchemas` block of `McpToolRegistry.kt`, which this subtask may move into the tool declarations unchanged), the whole `src/test` and `src/repoTest` trees, `runtime-kotlin/runtime-mcp/build.gradle.kts`, `RuntimeComponent` in `runtime-core` `skillbill.di` for an exposed `Clock`, `ReviewService.previewImport` in `runtime-application` for an additive `stdinText` parameter, the owning `*PayloadKeys` objects in `runtime-contracts` for keys this module reads or writes that have no constant yet, a new typed error under `ShellContentContractException` in `runtime-contracts` `skillbill.error`, `WireVocabularyGovernedSeamInventory` in `runtime-core` tests, `runtime-kotlin/ARCHITECTURE.md` (the `runtime-mcp` module entry, the `skillbill.mcp` package entry, and the CLI/MCP data gateway section), and `runtime-kotlin/agent/decisions.md`.

Build the graph once: `Main.kt` resolves the environment, creates one `RuntimeComponent` and one `McpComponent`, and runs the server with it. `McpComponent` exposes the eight services and the `Clock` as abstract vals; `McpInsightServices`, `McpOperationsServices`, `McpRuntimeServices`, `services()`, `mcpClock()`, and `McpRuntimeContext` are deleted. Handlers take `(arguments, component)` and call the service they need; the `McpRuntime`, `McpRuntimeLifecycle`, `McpWorkflowRuntime`, and `McpScaffoldRuntime` objects dissolve into the handlers, keeping each mapper and each `autoSync` call where it is today. Review text is passed to `previewImport` and `importReview` as an argument.

Declare each tool once: an `McpTool` value with `name`, `description`, `inputSchema`, `handler`, and an optional argument normaliser, in one ordered list that replaces `toolNames`, `descriptions`, `inputSchemas`, and `nativeHandlers`; `tools/list` and dispatch read the list. The `quality_check_finished` normaliser moves into that tool's declaration and drops the two constant fields of `NormalizedQualityCheckStack`; the three runtime-owned keys leave the advertised schema and their presence in a request is a typed error.

One framer: a `core` object owning request parsing, `initialize`, `ping`, `tools/list`, `tools/call` envelopes, success and error responses, the JSON-RPC codes, and the protocol version constant; `McpStdioServer` and `GovernedReviewEvidenceBridge` both use it. The bridge uses `GovernedReviewEvidenceConnection.connect`; its private `Connection`, `connect`, `openSocketChannel`, and `initializeResult`, and `GovernedReviewEvidenceInitialization.kt`, are deleted.

Record or refuse: `McpToolArguments` raises the new typed error for a missing or mistyped declared key instead of defaulting; the unknown-tool, remote-stats workflow, and `attempt` errors use it; `captureException` emits one `RuntimeDiagnostics` record when the capture itself fails; the validator's WARNING log is removed and the typed error stays; the scaffold payloads drop `duration_seconds` or carry `TelemetryMeasurementAvailability.UNAVAILABLE_UNSUPPORTED`, whichever the parent skills' embedding contract needs, with the choice recorded in `decisions.md`; the `historyRelevance`, `historyHelpfulness`, and `failureDisposition` defaults reference their owners.

Keys: every argument key and output key becomes a `runtime-contracts` constant, adding the missing ones to the owning `*PayloadKeys` objects; JSON-RPC and JSON-Schema structural keys live in one `core` object; the duplicated `read_only_full_state_command` builder becomes one function; `updateCheck` uses an `UpdateCheckContract` in `runtime-contracts` like `doctor` and `version`. Register every payload-reading or payload-writing file in `WireVocabularyGovernedSeamInventory`.

Fold the two alias constants, the four files under 20 lines, and the `skillbill/infrastructure/fs/contracts` classpath path (rename the generated resource directory to `skillbill/mcp/contracts` in `build.gradle.kts` and `TelemetryEventSchemaPaths`). Move `TestSupport.kt` into `skillbill.mcp`. Make every top-level declaration except `main` `internal`.

## Acceptance Criteria

1. `Main.kt` is the only production site that calls `RuntimeComponent::class.create` or `McpComponent::class.create`; `grep -rn "McpRuntimeContext\|fun services(\|fun mcpClock(" src/main` returns nothing; `McpInsightServices`, `McpOperationsServices`, and `McpRuntimeServices` are deleted; `McpComponent` exposes `learningService`, `lifecycleTelemetryService`, `telemetryService`, `reviewService`, `systemService`, `workflowService`, `updateCheckService`, `featureTaskPhaseSettlementService`, and `clock` as abstract vals; a test proves two sequential `tools/call` requests on one server observe the same `DatabaseSessionFactory` instance.
2. `ReviewService.previewImport(input, stdinText)` exists; `McpRuntime.importReview`'s `stdinText = reviewText` context construction is gone; the `import_review` golden fixtures and `McpStdioServerDispatchTest` pass with unchanged assertions.
3. `McpToolRegistry.toolNames`, `descriptions`, `inputSchemas`, and `McpToolDispatcher.nativeHandlers` are replaced by one ordered `List<McpTool>` whose elements carry name, description, input schema, and handler; `tools/list` order and every description are unchanged, proven by `McpStdioServerTest.tools list exposes the expected inventory`; `grep -rn '"quality_check_finished"' src/main` matches only that tool's declaration; `NormalizedQualityCheckStack` is gone.
4. One `core` framer object owns `initialize`, `ping`, `tools/list`, `tools/call`, `successResponse`, `errorResponse`, the JSON-RPC codes, and `MCP_PROTOCOL_VERSION`; `McpStdioServer.kt` and `GovernedReviewEvidenceBridge.kt` contain no `"jsonrpc"`, `"protocolVersion"`, or numeric JSON-RPC code literal; a test proves both modes answer an unparsable line with code `-32700` and `ping` with an empty result.
5. `GovernedReviewEvidenceBridge.run` obtains its connection from `GovernedReviewEvidenceConnection.connect`; the bridge's private `Connection`, `connect`, `openSocketChannel`, and `initializeResult` and the file `GovernedReviewEvidenceInitialization.kt` are deleted; a test over a local Unix socket proves a forwarded response longer than `RESPONSE_FRAME_BYTES` raises `GovernedReviewEvidenceTransportError` and that a handshake refusal raises the same error type; `GovernedReviewEvidenceBridgeTest` passes with unchanged assertions.
6. `grep -rnE 'arguments\.[a-zA-Z]+\("[a-z_]+"' src/main` and `grep -rnE '"[a-z_]+" to ' src/main` return only lines inside the one `core` object that owns JSON-RPC and JSON-Schema structural keys; `WireVocabularyGovernedSeamInventory` lists every file under `skillbill/mcp` that reads or writes tool payloads; `WireVocabularyArchitectureTest` passes and fails on a synthetic `arguments["session_id"]` read added under a registered path; `read_only_full_state_command` is built in one function; `McpRuntime.updateCheck` returns `UpdateCheckContract(...).toPayload()`.
7. A new typed error under `ShellContentContractException` in `runtime-contracts` names the tool and key; `McpToolArguments` raises it for a missing or mistyped declared key and no longer returns `""`, `false`, or a caller default for one; the unknown-tool, `mapRemoteStatsWorkflow`, and missing-`attempt` paths raise it; `grep -rn "error(\|require(\|requireNotNull(" src/main` returns nothing; `RUNTIME_OWNED_QUALITY_CHECK_KEYS` are absent from the advertised `quality_check_finished` schema and a request carrying one is refused with the typed error; `captureException`'s `runCatching` is gone and a test proves a failing capture emits one `RuntimeDiagnostics` record naming the tool; `grep -rn "java.util.logging" src/main` returns nothing; `McpQualityCheckTelemetryNormalizationTest` and `McpStdioArgumentShapeUnifiedContractTest` pass with assertions updated only for the new error message text.
8. `SCAFFOLD_TELEMETRY_DURATION_SECONDS` is gone and neither scaffold payload reports a numeric `duration_seconds` that was not measured; the `- "session_id"` subtractions are gone; `McpLifecycleToolHandlers` and `McpFeatureTaskSettlementHandlers` contain no `"none"` or `"needs_user_action"` literal; `McpRuntimeTest.new skill scaffold preserves standalone and orchestrated payload envelopes` passes with its golden fixture updated only for the duration field, and `decisions.md` records the choice.
9. Every top-level declaration under `src/main` except `main` is `internal` or `private`; `TestSupport.kt` is in package `skillbill.mcp`; the generated schema resource path is `skillbill/mcp/contracts/telemetry-event-schema.yaml` in both `build.gradle.kts` and `TelemetryEventSchemaPaths`, and `TelemetryEventSchemaCleanupTest` passes; the two `TELEMETRY_EVENT_SCHEMA_*` alias constants and `McpLearningPayloads.kt`, `WorkflowContinueMcpMaps.kt`, and `TelemetryEventSchemaPaths.kt` are folded into their users; `./gradlew :runtime-mcp:test :runtime-mcp:repoTest` passes with zero failures and the four `runtime-mcp` baselines are unchanged and empty.

## Validation strategy

Name the regression before each test: a second request rebuilding the graph and losing process-held state, review text read from the real stdin instead of the argument, a tool advertised but not dispatchable, a parse error answered with the wrong code, an evidence frame over the cap read to exhaustion, a misspelled key silently defaulted to `""`, a client-supplied `completion` silently dropped, an exception capture that fails without a trace, a zero-second duration reported as measured, a sibling module compiling against a re-exposed internal. Drive the server through `handleLine` and the built distribution over stdio; assert payload bytes against the golden fixtures. Run the module suites, `runtime-application` tests for `ReviewService`, `runtime-core` architecture guards including `WireVocabularyArchitectureTest`, `RuntimeLayerBoundaryArchitectureTest`, `PrincipleEnforcementInventoryTest`, and both ambient recorders, and `./gradlew check` on `runtime-kotlin`; run the pack-declared quality gate and `bill-unit-test-value-check` for changed tests.

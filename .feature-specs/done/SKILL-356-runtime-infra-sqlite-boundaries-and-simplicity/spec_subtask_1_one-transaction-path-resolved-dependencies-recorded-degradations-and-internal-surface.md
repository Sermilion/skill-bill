## Acceptance Criteria

1. `core` has one transaction function taking the database path, a begin mode (`IMMEDIATE` or `DEFERRED`), and a `DatabaseAccessOperation`; `read`, `readIfPresent`, `transaction`, and `DatabaseMigrations.apply` use it; `SQLiteDatabaseSessionFactory.inTransaction`, `inReadTransaction`, `ConnectionTransactions.inImmediateTransaction`, `TriageRuntime.inTransaction`, `TriageRuntime.recordFeedback`, and `ReviewRuntime.saveImportedReview(Connection, ImportedReview, String?)` no longer exist; a test proves a repository `SQLException` inside `transaction {}` surfaces as `DatabaseAccessError` with the write operation and that the transaction rolled back; `ConnectionTransactionsRollbackTest` passes with its current assertions.
2. `SQLiteDatabaseSessionFactory(context, clock, diagnostics)` is the only constructor; `withProcessDefaults` and every `System.getenv()` or `System.getProperty("user.home")` default in `DatabaseRuntime` and `DatabasePaths` are gone; a sentinel `EnvironmentContext` raises a typed error under `SkillBillRuntimeException` naming the unresolved field; `RuntimeBootstrapBindings.databaseSessionFactory` passes the resolved context, the bound `Clock`, and the bound `RuntimeDiagnostics`; `RECORD_ARCHITECTURE_BASELINES=1` leaves `runtime-infra-sqlite-ambient-environment-baseline.txt` empty and adds no row elsewhere; every test that constructed the factory passes an explicit environment map.
3. `grep -rn "java.util.logging" src/main` returns nothing; `ReviewStatsArithmetic.durationSeconds`, `LifecycleTelemetryDurations.parseDurationSeconds`, `GoalTelemetryPayloads.durationBetweenSeconds` and `parseTelemetryTimestamp`, `SQLiteWorkListRepository` L134, `WorkflowGoalRunnerCrashReconcile` L15, `ReviewStageStateCodec` L40, `GoalRepositoryIdentity` L6, `WorkflowGoalRunnerChildWorkflowPersistence` L136-137, `DatabaseRuntime.closeQuietly`, and the four former `Logger.warning`/`severe` sites each raise a typed error for a corrupt durable row, return a closed availability state, or emit exactly one `RuntimeDiagnostics` record naming seam, expected value, and used value; tests prove the record for an unparsable duration and for an unparsable lease expiry, and prove `readUserVersion` raises `DatabaseAccessError(READ)`.
4. `ArchitectureScanGuardSupport` lists `OffsetDateTime.now`, `ZonedDateTime.now`, and `JvmSystemClock.instant` as ambient-clock markers with a synthetic-violation test for each; `StaleSessionReconciler`, `ReviewStageState`, `WorkflowStateWrites`, `WorkflowGoalRunnerBlockWrites`, and `WorkflowIdGeneration` read the injected `Clock`; `WorkflowIdGeneration` takes its random source as a parameter; `runtime-infra-sqlite-ambient-clock-baseline.txt` is empty and no other module's clock baseline grows.
5. `FindingOutcomeType` in `runtime-domain` `skillbill.review.model` declares the five tokens with `wireValue`; `DatabaseSchemaStatementsEarly` and `FeedbackEventMigration` build their `CHECK` constraints from it; `ReviewFindingStats`, `ReviewHealthAggregation`, `LearningsRuntime`, and `TriageDecisionParser` reference it; no production file spells any of the five tokens as a string literal; every telemetry payload key spelled in `infrastructure/sqlite/telemetry/` and `infrastructure/sqlite/review/` is a `*PayloadKeys` constant; both directories are path markers in `WireVocabularyGovernedSeamInventory`; `WireVocabularyArchitectureTest` passes and fails on a synthetic inline `"session_id"` access under a registered path; `LifecycleTelemetryTruthfulnessTest`, `GoalTelemetryStoreTest`, and `ReviewStageTelemetryTest` pass with unchanged assertions on payload bytes.
6. `SQLiteUnitOfWork` and the `UnitOfWork` port expose `featureTaskPhaseSettlements: FeatureTaskPhaseSettlementRepository`; `SqliteFeatureTaskPhaseSettlementRepository` calls `database.transaction` and `database.read` and imports nothing from `core`; `WorkflowGoalRunnerPurgePersistence` takes repositories from the unit of work; `SQLiteUnitOfWork.rawConnection` and the `as SQLiteUnitOfWork` cast are deleted; `SqliteFeatureTaskPhaseSettlementRepositoryTest` and `GoalRunnerPurgePersistenceTest` pass with unchanged assertions.
7. `PreparedStatement.bindAll(vararg values: Any?)` in `core` is the only positional binder; `grep -rn "PARAM_" src/main` returns nothing; `SqlParamIndexes.kt` and `DbConstants.kt` are deleted, with `SKILL_BILL_REVIEW_DB` and `defaultDbPath` beside `DatabasePaths` and the three row-format version constants beside their writers; `FileRejectedOutputDiagnosticPermissions` checks the `posix` attribute view, records and returns when absent, and raises `RejectedOutputDiagnosticError.Persistence` on `IOException`, proven by a test that runs it against a `FileSystem` without the view; `build.gradle.kts` declares no `libs.jackson.databind`, `libs.jackson.dataformat.yaml`, or `libs.json.schema.validator`; every production file under 20 lines is folded into its user unless it declares an enum or data class referenced from more than one package.
8. `src/testFixtures` exposes one function establishing a temporary database through `DatabaseRuntime.establishSchemaReadiness` and returning its path and connection, and one returning a `SQLiteDatabaseSessionFactory` bound to a path with an explicit environment, a fixed `Clock`, and a recording `RuntimeDiagnostics`; the 23 test files in `runtime-cli`, `runtime-core`, `runtime-mcp`, and `runtime-engine` use `testFixtures(project(":runtime-infra-sqlite"))` and no test outside this module imports `skillbill.infrastructure.sqlite.core`; the ten tests under `src/test/kotlin/skillbill/review/` are in package `skillbill.infrastructure.sqlite.review` with unchanged assertions; `ReviewFinishedLearningsPayloadTest.kt` and `src/test/kotlin/skillbill/application/learning/LearningSessionWireTestSupport.kt` are deleted; every top-level declaration is `internal` or `private` except `SQLiteDatabaseSessionFactory`, `SqliteFeatureTaskPhaseSettlementRepository`, `WorkflowGoalRunnerManifestStore`, and `WorkflowGoalRunnerOutcomeStore` (and, until subtask 2 lands, `WorkflowGoalRunnerOutcomeStoreBridgeBuilder`); the four test hooks on `DatabaseRuntime` and `DatabaseIdentity` are deleted and `DatabaseWriteReadinessTest` observes repeated work through the recording diagnostics port or a counting fixture connection; `./gradlew :runtime-infra-sqlite:test` passes with zero failures.
